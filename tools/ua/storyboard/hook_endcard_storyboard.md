# 주방 대전쟁 트레일러 — 후킹·엔드카드 컷 설명

- 규격: 1080×1920 세로, 30fps, 자막 없음
- 화풍: 게임 오프닝 영상·게임 그림과 같게 (두꺼운 진갈색 외곽선, 손그림 느낌)
- 등장: 셰프 곰, 토마토·당근·브로콜리(+감자·버섯·마늘), 대왕 양파, 프라이팬 — 게임에 있는 것만
- 생성 이미지에 글자·로고 넣지 않기

## 후킹 (0.0–3.0초)

### 컷1 · 0.0–0.5초 — 냉장고 쾅, 초록 연기
- 밤의 주방, 파란 톤. 냉장고가 화면 가운데 정면 (가로 50%, 높이 70% 지점)
- 냉장고 문이 쾅 열리며 초록 연기 폭발, 0.3초 만에 화면 70%를 덮음
- 소리: 문 쾅 + 쉬익

### 컷2 · 0.5–1.3초 — 군단 등장
- 연기가 걷히며 채소 군단 실루엣이 드러남
- 로우앵글, 지평선은 아래에서 35%
- 맨 앞 토마토·당근·브로콜리 3마리가 화면 아래 1/3에 크게, 뒤로 갈수록 작게 20~30마리
- 뒤쪽 위에 대왕 양파 실루엣 (왕관·망토)
- 빨간 눈 수십 쌍이 동시에 번쩍
- 카메라 천천히 뒤로 빠짐
- 소리: 낮은 웅성 → 눈 번쩍 '팅'

### 컷3 · 1.3–2.1초 — 돌진
- 군단이 카메라 쪽으로 돌진
- 맨 앞 토마토가 입을 크게 벌리고 0.6초 동안 화면 30% → 85%로 커짐
- 속도선, 화면 흔들림
- 소리: 우르르

### 컷4 · 2.1–2.6초 — 셰프 곰 결의
- 셰프 곰이 프라이팬을 들고 결의에 찬 표정
- 허리 위 샷, 화면 가운데
- 배경은 오렌지 집중선 (오프닝 영상 곰 컷과 같은 톤)
- 팬이 반짝
- 소리: '챙'

### 컷5 · 2.6–3.0초 — 스윙 → 게임 화면
- 곰이 팬을 오른쪽 위 방향으로 휘두르는 동작 중간
- 흰 번쩍 → 대군 모드 게임 화면으로 하드컷 (맞는 장면은 안 보여 줌)
- 소리: 휘익 + 게임 BGM 시작

## 엔드카드 (27.0–30.0초)

- **로고와 '지금 플레이' 버튼은 처음부터 끝까지 계속 화면에** (사내 기준)
  - 로고: 위쪽 가운데 (y 150–562)
  - 버튼: 아래 가운데 (y 1500–1704)
- 곰·채소는 로고와 버튼 사이 (y 600–1440)에서 움직임. 날아가는 채소는 로고·버튼 뒤로 지나감
- 앞 장면(장소 분할)에서 하드컷 + 흰 번쩍으로 시작

### 컷1 · 0.0–0.5초 — 포위
- 채소 군단에 빙 둘러싸인 셰프 곰, 화면 가운데
- 채소들이 곰 쪽으로 조여 들어오고, 곰은 팬을 머리 뒤로 젖혀 준비
- 소리: 환생 효과음 (지금 것)

### 컷2 · 0.5–1.2초 — 프라이팬 스매시
- 곰이 팬을 한 바퀴 크게 휘두름 (흰 원형 잔상)
- 맞은 채소들이 빙글빙글 돌며 사방으로 화면 밖까지 날아감
- 화면 흔들림
- 소리: 휘익 + 퍽

### 컷3 · 1.2–3.0초 — 승리 포즈
- 채소가 다 날아간 뒤 곰이 팬을 어깨에 걸치고 씩 웃음
- 끝까지 숨쉬듯 살짝 움직이고, 팬이 가끔 반짝
- 소리: BGM 마무리
